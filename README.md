# 📚 Library Management System

A modern and user-friendly **Library Management System** developed for **Software Engineering 1 – Module 7** using Vue.js and Vite.

The system allows librarians to organize, manage, search, add, edit, and delete book records through a clean and responsive interface.

## ✨ Features

- 📊 Library dashboard
- 📚 Book collection management
- ➕ Add new books
- ✏️ Edit existing book records
- 🗑️ Delete book records
- 🔎 Search books, authors, and categories
- 🏷️ Book categories
- 📖 Available and Borrowed status
- ✅ Form validation
- 🔔 Success and error notifications
- 💾 LocalStorage data persistence
- 🌙 Night Mode
- ☀️ Light Mode
- 📱 Responsive user interface
- 🎨 Modern and user-friendly design
- ⚡ Smooth transitions and animations
